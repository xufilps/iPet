# 阶段3AI：说话内/外置布局与长文本滚动 — 2026-10-03

依据1a06c598 Setting.MessageBarOutside、winGameSetting.SwitchMsgOut、MessageBar.SetPlaceIN/OUT及XAML ScrollViewer MaxHeight400、TText_SizeChanged.ScrollToEnd：内置下对齐角色区域，外置使用500偏移置于角色下方，长文本滚动至新输出。原WPF角色缩放/控件坐标不能直接映射AppKit。

新增本机“自动避让（既有默认）/角色内/角色外”三种模式。内置按角色底部定位并限制宽高在角色区域内，外置优先下方、空间不足上方；最终均夹到物理显示器可见范围。自动模式保留既有气泡避开工具栏策略，显式内/外用真实角色框，不把工具栏算角色高度。统一原生points，固定可读字号，属于原生适配，默认自动与原版默认内置不同需标明。

长文本使用独立可滚动视口，按完整文字预先测量高度以避免逐字窗口跳动，视口只显示已输出文字并滚动至末尾；保持4000字显示边界、不改变输出/停留/淡出和复制语义。根据模式/屏幕/角色尺寸变化重新布局，不重启播放；宽度随窄屏或内置角色宽度换行，不能只夹窗口而保留超宽内容。无有效屏幕安全隐藏。只改本机偏好/界面，JSON v7/资源不变，选择式文本/语音仍缺。
