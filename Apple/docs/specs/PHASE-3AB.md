# 阶段3AB：原生说话栏播放节奏 — 2026-10-03

用户要求持续推进原版体验；本批修改已有离线气泡显示流程，不新建聊天/网络接口。依据1a06c598 Core/Display/MessageBar.xaml.cs和Handle/Function.ComCheck：每150ms显示2字符；剩余文字为空的下一次tick开始停留，停留(标点数*10+20)*200ms；初始透明度0.8，停留后每50ms减0.02至<=0.05，下次tick关闭。标点集合含中英文逗号句号叹号问号分号冒号及换行，先去CR再将双换行替换单换行。
