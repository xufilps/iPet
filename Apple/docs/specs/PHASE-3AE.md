# 阶段3AE：移动区域与原生区域选择 — 2026-10-03

依据1a06c598 MWController.ScreenBorder/ResetScreenBorder/GetWindowsDistance四方向、SetNowScreenActivate，Setting.MoveAreaDefault/MoveArea及winGameSetting的默认/检测/自定义入口、winMoveArea.Save_Click。原版主屏幕边界或持久化矩形用于全部移动/侧挂距离；检测当前显示器转换DPI坐标；自定义可拖动/缩放窗口，保存其矩形，取消不改设置。自动换屏/自动回正为其他规则，尚不借本批宣称完成。

本批提供当前屏幕（保留既有iPet默认行为）、主屏幕、检测当前屏幕并固定矩形、自定义可拖动缩放区域窗口。原生AppKit统一points、左下原点；采用visibleFrame避开菜单栏/Dock，区别于原版整屏。区域选择保存窗口外框，取消不写入；所有移动候选、持续移动、侧挂、位置恢复共用有效区域；气泡/工具栏仍按物理屏幕定位。选择设置取消当前手势/移动并恢复可见位置，避免旧边界计划延续。

纯几何解析器验证有限坐标与正尺寸、自定义矩形和当前可用屏幕交集、宠物尺寸容纳；跨屏矩形暂取最大可用交集，不允许移动穿过显示器间空洞。屏幕移除、非法/过小/不相交区域时退回角色所在可用屏幕，保留原始自定义偏好并显示回退提示，不静默写回。增大角色时同样解析。模式和矩形仅本机UserDefaults，smoke隔离且不改JSON v7。主屏采用NSScreen.screens.first，避免NSScreen.main随焦点改变。

实施顺序：规格检查点→几何回归先失败→解析器及原生窗口/设置接线→完整构建与回归→源码审查、文档交接和推送ipet-dev。覆盖主屏/当前屏、负坐标、交集裁剪、屏幕移除回退、非法/过小、无屏幕，保存与取消路径检查。原README尾部/许可及main镜像保留；真实选择窗口、多屏/睡眠/压力仍留后。回滚本批提交即可，忽略新增本机偏好，无存档转换。
