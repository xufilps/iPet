# 阶段5E：日程队列与执行 — 2026-10-02

目标为还原原版日程编辑、循环执行与套餐门槛；依赖5C倍率与5D套餐。源码基线1a06c598：Windows.Interface/ScheduleTask.cs（AddWork/AddStudy/AddRest、Start/Stop/StartWork、RestTimer_Elapsed、WorkTimer_E_FinishWork），Windows/WinDesign/winWorkMenu.xaml.cs（添加门槛、相邻等待累加、删除/排序），Core/Graph/GraphHelper.cs（Work.Time为整数分钟）。不补算退出/睡眠/时钟跳变期间状态，不启动真实用户存档或压力测试。

## 任务1：队列模型与编辑

纯Swift Codable队列，稳定递增ID，工作/学习/娱乐统一活动ID及倍率，等待以分钟保存；添加、删除、上移/下移不更改其他项目身份。原UI添加工作/学习须活跃套餐及有效倍率后的LevelLimit授权，娱乐须宠物15级；队列添加不续费、不扣款、不开始活动。相邻等待合并，原入口每次30分钟，模型允许正整数分钟以支持原已保存配置。未知活动ID在解码时保留供执行时明确报错，不静默丢弃。

原生边界：最多1000项、等待1...1440分钟、倍率1...400、ID1...1e12；整队列验证、失败事务不变。运行时禁止编辑（暂停也禁止，需停止后编辑），以免活动完成回调推进到错项。队列模型本身尚未意味着用户可以使用日程；本任务不改变应用存档版本或现有功能，后续接入时升级。测试先RED后GREEN：顺序/身份/合并、移动/删除、满容量/整型溢出/非法倍率与等待、套餐到期/授权/宠物门槛、不扣款不续费、未知ID往返及损坏拒绝。

## 任务2：执行与存档

PetState可选日程，ActivitySession可选所属项目ID；运行/暂停/下一索引/当前项目及等待余额可保存。启动从第一项开始，循环回到首项；每次开始工作或等待前按工作后学习检查一次续费，依5D原余额严格大于价格/授权下降/续费开关关闭规则。执行套餐门槛按基础活动LevelLimit（原添加时却按倍率后的要求），宠物等级不足逐级降倍率并保存，最终仍不可启动则关闭日程并说明；不保留原静默卡住。等待不强制睡觉；活动完成后30秒衔接，半程前中止关闭日程。半程用整数分钟Time/2截断，非简单秒数除二。

停止日程不强制停止当前活动；手动替换活动或主动休息明确退出日程，防止后续自动覆盖用户选择。暂停关联活动与等待一起暂停；恢复重新校验活动状态。活动完成只推进同属日程的会话，过时事件不能污染新队列。时钟依现有tick有效delta0...30，等待只扣本次开始前已存在的等待，刚生成30秒衔接不能被之前活动时间扣掉；退出/睡眠不补算。加载/导入暂停日程与活动，不隐式续费。JSON v7，升级独立保留v1...v6原件，未来v8保护；未知项目保留可删除。
