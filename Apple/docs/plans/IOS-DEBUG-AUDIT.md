# iOS 首版全面排查

## 范围与基线

基线 e065036a；复查 iOS 生命周期、操作链路、动作与消息打断、设置与存档恢复，并执行共享核心、资源工具和 macOS 构建回归。保留现有七个 iOS 文件的编辑器 SDK 标记。最低支持 iOS / macOS 26，iOS 角色不自主移动，不扩展多角色、云存档或联机。

## 实施与验证

1. 独立源码审查，运行现有验证，区分可复现缺陷与待验证风险。
2. 补充确定性生命周期、消息与恢复用例；发现缺陷先记录复现，再最小修复。
3. 检查模拟器 iPhone / iPad 启动和实际画面，复查工程生成一致性、资源闭包、许可证与存档兼容。
4. 记录修复、验证证据和设备限制，提交检查点并推送 ipet-dev。

## 风险、边界与恢复

测试使用隔离存档和设置，不能覆盖日常养宠数据；不更改存档版本。模拟器证据不能替代真机触摸、系统睡眠或多屏检查，长期压力测试仍按之前约定留到最后。回滚本轮修复提交即可恢复基线行为；不改上游镜像 main。
