# 对照原版的剩余功能 — 2026-10-02

复核基线为原版 `1a06c598`；当前清单随阶段3I更新。原C#依据来自保留Git历史，当前实现以Swift源码为准。完整状态与来源见 [UPSTREAM_COMPARISON.md](UPSTREAM_COMPARISON.md)；以下按用户能观察到的体验组织缺口。

## 后续兼容与生态

多角色、数据型MOD、主题/本地化文本和LPS旧档导入尚未实现；三者与C#插件ABI兼容分别处理。排程、图库、DIY菜单/链接、开发者控制台、报告等尚未迁移；图库素材授权另行核对。语音播放框架尚无原生实现，先确认实际语音来源与授权，不将框架接口误写成内置角色完整语音。

Steam、工坊、云存档、联机、联网聊天和C#插件需要独立接口/生态研究，不承诺直接兼容。开机启动需macOS登录项方案，原首版默认排除。iOS仅共享模块编译，无完整应用界面；Developer ID签名、公证及正式安装包尚未交付。这些不阻塞优先补齐本地桌宠玩法。
