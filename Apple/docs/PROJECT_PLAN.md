# VPet Apple 原生版实施计划 — 2026-10-01 / v0.1

目标：macOS 14+ 基础桌宠，Swift 6；共享核心与动画支持 iOS 17+，iOS 应用后续实现。

## 范围与结构
- Apple/Sources/PetCore：养成、命令、时钟、随机源、版本化 JSON 存档。
- Apple/Sources/PetRendering：资源清单、SpriteKit 播放、区域映射。
- Apple/Sources/VPetMac：AppKit 窗口、SwiftUI 面板、生命周期和菜单栏。
- Apple/scripts：内置素材转换、构建和验证。生成素材忽略，不重复提交原图。
- 复用萝莉斯内置角色，支持待机、拖动/提起、摸头/身体、移动、休息、免费食物和饮料。
- 不支持 Windows 存档、第三方 MOD、Steam、插件、AI、云同步、商店分发和开机自启。

## 工作阶段
